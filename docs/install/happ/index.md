## Как подключать подписку
Рекомендуется:
- `Способ 1` - автоматический deeplink из бота (`Подключиться`).

Если deeplink не сработал:
- `Способ 2` - ручной импорт ссылки подписки через буфер обмена или вставку в клиенте.

## Что подготовить заранее
- Активную подписку MoonlumeVPN.
- Доступ к Telegram-боту или странице подключения.
- Установленный клиент Happ (или совместимый клиент для вашей платформы).
