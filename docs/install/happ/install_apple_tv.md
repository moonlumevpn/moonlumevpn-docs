## Что понадобится
- Активная подписка MoonlumeVPN
- Telegram-бот или сайт с кнопкой подключения
- Устройство Apple TV

## 1) Установите приложение Happ
Рекомендуемый способ:
- Нажмите кнопку установки в боте или на сайте.

Если кнопка не открывается:
- App Store: [Happ Proxy Utility for TV](https://apps.apple.com/us/app/happ-proxy-utility-for-tv/id6748297274)

Подробная инструкция:
- [Apple TV (tvOS) FAQ](https://www.happ.su/main/ru/faq/apple-tv-tvos)

## 2) Добавьте подписку
Рекомендуемый способ:
- Нажмите `Подключиться` в боте (deeplink).
- На открывшейся странице выберите Apple TV, если платформа не определилась автоматически.

Если deeplink не сработал:
1. Скопируйте ссылку подписки в боте.
2. Откройте Happ на Apple TV.
3. Импортируйте подписку вручную в приложении.

## 3) Подключитесь
1. Выберите сервер.
2. Нажмите `Подключиться`.
