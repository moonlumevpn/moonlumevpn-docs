## Статус
На данный момент клиент Happ для Linux не поддерживается.

## Что делать сейчас
1. Используйте другое поддерживаемое устройство: Android, iOS, macOS, Windows, Android TV или Apple TV.
2. Либо используйте альтернативный Linux-клиент (будет добавлен отдельной инструкцией позже).
